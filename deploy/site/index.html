A first Java program

Save this as HelloJava.java. With a JDK installed, compile it using javac HelloJava.java, then run java HelloJava.

public class HelloJava {
    public static void main(String[] args) {
        String language = "Java";
        System.out.println("Hello, " + language + "!");
    }
}

The class name matches the file name. The main method is the entry point, and println writes a line to the console.

Try a small project

Build a command-line reading list. Store book titles in an ArrayList<String>, add new titles, and print the list. Then extend it with a menu and file storage.

Keep each step small: make it work, test an edge case, and improve the names before adding another feature.
